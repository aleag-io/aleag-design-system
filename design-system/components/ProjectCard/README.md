# ProjectCard

A portfolio tile for the Work index, built on `Card`: 4:3 media, the service line as an eyebrow, a title, one sentence, up to three stack tags and the year.

- **Consumer provides:** `title`, `href` (the case-study page), `line`, `summary`, `media` (an `img` with real `alt` text), `tags`, `year`.
- `line` sets the eyebrow: `technology` (default) → "Technology", `software` → "Software", `home` → "Home lab", `workshop` → "Workshop". Workshop tiles switch the eyebrow and tags to `workshop-text`.
- Grid: one column under `bp-sm`, two from 600 px, three from 1024 px, `space-6` gaps.
- Photograph workshop pieces on a plain ground in daylight; for software and technology work, use a cropped screenshot or a simple diagram, never stock imagery.
- Never name a client without permission. Describe the client by sector ("A regional credit union") in the summary.
