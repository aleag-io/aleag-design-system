# EmptyState

A placeholder for an empty list: a blog with no posts yet, or a filter that matches no projects.

- **Consumer provides:** `title`, a sentence as `children`, and one or two `action`s.
- Say what will be here and offer a next step ("Subscribe via RSS", "Clear filters"). No "Oops", no apology.
- For a filter with no results, the title names the filter ("No woodworking posts yet") and the action clears it.
- `art={false}` hides the small illustration (a ring and a bar) when space is tight.
