# Badge

A short status or category label, one or two words.

- **Consumer provides:** `children` (the word), `tone`, optional `dot`.
- Status tones (`success`, `warning`, `danger`, `info`) always carry a word that names the state ("Paid", "Overdue"); color is never the only signal.
- `accent` is for one promotional highlight per view ("New"). `primary` for categories and durations. `neutral` for everything else.
- Sentence case, no trailing punctuation.
