# ProjectFacts

The facts row under a case study's header: client, role, timeline, stack and the result, as a definition list.

- **Consumer provides:** `items` (`{ label, value, emphasis? }`). Four or five items; mark the one measurable outcome with `emphasis`, which sets it in `title` type and `primary`.
- Labels are `overline` style: Client, Role, Timeline, Stack, Outcome. Values are short phrases, not sentences.
- Name the client only with permission; otherwise use the sector.
- Workshop pieces use the same row with Wood, Joinery, Finish, Size ("450 × 450 × 560 mm"), Time.
